# TechVerse ISP Digital Platform Demo

A pitch-ready Next.js concept demo for an ISP customer-facing digital platform.

## Important
This is a **TechVerse concept/demo**, not a commissioned B NET system. All package names, prices, service metrics, coverage, customer records and tickets are illustrative.

## What is included
- Home / customer acquisition journey
- Plans and package comparison
- Coverage checker
- Installation request workflow
- Customer support ticket workflow
- Customer self-service portal
- Responsive styling
- Demo/placeholder operational data

## Stack
- Next.js 16.3.3
- React 19
- TypeScript
- Tailwind CSS 4

Next.js 16.3.3 is an Active LTS release as of August 2026; use current security releases when deploying to production. See the official Next.js support/release information.

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000
